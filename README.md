# TenK_Graph

10-K filings are huge!

But, they contain essential information for anyone interest in studying the business outcomes of big companies.

As a visual learner, I've decided to take Apple's Latest 10-K and store it as a Knowledge Graph in Neo4j, instead of a flat document. 

You can try this code out yourself, with other companies. Just change ay references of Apple to another group, like NVIDIA. The pipeline here is meant to be generalizable to all companies.
